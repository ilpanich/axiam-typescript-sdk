    Interface AuthorizationRequest

    The result of oidcBegin — everything the caller needs to start an authorization-code + PKCE login (CONTRACT.md §12.1).

    Remarks

    The caller owns this state (§12.3 rule 1). The SDK stores nothing: it keeps no copy of state, nonce or codeVerifier in process-global state or any implicit cache. Persist all three in your own HTTP session (or in an OidcStateStore), redirect the browser to url, and pass nonce + codeVerifier back into oidcExchange when the code arrives.
