    subject

    subject: string

    The certificate's common name, e.g. device-001: a bare name or one CN= component, at most 64 characters (RFC 5280 ub-common-name), printable — a control character, tab or line break, an invisible or bidirectional formatting character, or two spaces in a row is refused with 400. A name that is to be written into another system's configuration (a FreeRADIUS table, an ACL) should match ^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$.
