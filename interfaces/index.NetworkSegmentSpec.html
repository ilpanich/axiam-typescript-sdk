    Interface NetworkSegmentSpec

    A network segment (CONTRACT.md §27.6.2 item 1, contract 1.62).

    The natural key is site + kind + name, where kind is the wire spelling — 'access' or 'quarantine', the value createSegment writes and every segment read returns. This SDK keeps no mapping between it and anything else and has no zones spelling (zones is a server-side path segment). The three are never drift (a segment's kind, site and name do not change, §36.3 rule 4); every other member is a field.

    A member left off is silent (rule 3): it never drifts, and an Update carries the read's value for it. A member stated as null is "none" — the key is left out of the write, which is how a replacement clears an optional member.
