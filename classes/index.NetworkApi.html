    Class NetworkApi

    The network namespace handle.

    A tenant's network segments and the RADIUS reply profile each owns (RADIUS Live profile): a segment is a node of the reserved /network subtree of the resource tree (kind, VLAN, Filter-Id envelope, placement rank), and its profile is the typed axiam-radius-reply/1 record a decision renders. Every write is conditional on the version the caller read and passes the server's write gate. The tenant's Session-Timeout cap is one more row of it (get_policy, replace_policy): lowering it is always allowed, raising it is allowed and audited. The decision route FreeRADIUS calls is not in this registry.

    Acquiring one performs no I/O and allocates nothing meaningful (§27.2 rule 1); it holds the client and cannot be constructed without one.
