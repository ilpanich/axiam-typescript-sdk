    Function AxiamResource

    • AxiamResource(spec: ResourceSpec): ClassDeco

      Declare a resource on this class.

      Stack AxiamScope on the same class to declare scopes beneath it; decorator order does not matter, because each one only records into the class's bucket and collectManifest does the assembling.

      \@AxiamResource({ key: 'docs', name: 'documents', resourceType: 'collection' })
      \@AxiamScope({ key: 'draft', name: 'draft', description: 'Unpublished' })
      class Documents {}

      Decorator syntax needs your build to enable one of TypeScript's two decorator modes. Where it does not, apply it directly — it is the same call: AxiamResource(spec)(Documents).
