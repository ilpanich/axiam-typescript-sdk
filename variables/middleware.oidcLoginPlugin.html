    oidcLoginPlugin(options) (CONTRACT.md §12) — a FastifyPluginAsync registering the two "Login with AXIAM" routes: a login-redirect route and the callback route that consumes state, exchanges the code, and validates the ID token.

    Remarks

    The Fastify counterpart of Express's oidcLoginHandlers, built on the same beginOidcLogin / completeOidcLogin core, so the two frameworks cannot drift on flow semantics or error mapping. See oidcLoginHandlers for the returnTo open-redirect caveat and the onSuccess session-establishment contract, which apply identically here.

    Unlike axiamPlugin this plugin is deliberately encapsulated (no skip-override marker): it registers routes rather than a hook, so there is nothing that needs to escape its own context.

    Example

    await fastify.register(oidcLoginPlugin({
      client: oidc,
      store: new MemoryOidcStateStore(),
      redirectUri: 'https://app.example.com/auth/callback',
      onSuccess: (tokens) => { myAppSession.establish(tokens.idClaims!.sub); },
    }));
